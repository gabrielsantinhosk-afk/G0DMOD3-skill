# Trabalhar no G0DM0D3

Use esta skill quando a tarefa envolver o projeto G0DM0D3.

## Antes de fazer alterações

1. Leia o `README.md` e confira a estrutura atual do repositório.
2. Consulte os documentos relevantes, como `LOCAL_MODELS.md`, `API.md`, `SECURITY.md` e `CONTRIBUTING.md`, se existirem.
3. Verifique o estado do Git e preserve alterações existentes.
4. Não presuma que a documentação está atualizada: confirme os detalhes no código.

## Ao configurar ou executar

- Siga os passos documentados para iniciar a interface ou configurar provedores e modelos locais.
- Diferencie o site hospedado de uma instalação local.
- Explique quais chaves de API ou serviços externos são necessários para a tarefa.
- Nunca peça ao usuário para colar chaves secretas em arquivos versionados, commits ou logs.

## Ao modificar o código

- Faça a menor alteração que resolva o pedido.
- Siga os padrões já usados no projeto.
- Preserve as opções de privacidade e evite registrar prompts, respostas ou credenciais.
- Não afirme que o uso de modelos externos é privado sem confirmar o fluxo de dados com o provedor.

## Ao responder

- Informe quais arquivos foram alterados e o motivo.
- Diga como a mudança foi verificada; não alegue que algo foi testado se não foi.
